# 🚗 Car Blink

A modern, scalable and responsive car rental platform built with **Next.js, TypeScript, React Query, Axios, React Hook Form and Zod**.

Car Blink provides a seamless experience for users to explore cars, view car details, authenticate securely, and manage bookings through a modern and responsive interface.

---

## ✨ Features

### 🔐 Authentication
- User Login
- User Registration
- Forgot Password
- Form validation
- API-based authentication
- Error and success notifications

### 🚘 Car Management
- Browse available cars
- Car listing
- Car details
- Search cars
- Filter cars
- Car availability

### 📅 Booking
- Car booking
- Booking form
- Booking validation
- Booking status
- Booking history

### 🎨 UI / UX
- Fully responsive design
- Mobile-friendly interface
- Reusable UI components
- Loading states
- Error states
- Toast notifications
- Clean and modern design

### ⚡ Performance
- Next.js App Router
- Server-side rendering where required
- React Query caching
- Optimized API requests
- Reusable components
- Code splitting
